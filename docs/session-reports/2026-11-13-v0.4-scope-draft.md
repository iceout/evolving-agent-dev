## Good

The diagnosis is falsifiable rather than rhetorical: each item states what would
prove it wrong, and the direction items carry boundaries that prevent them from
being read as effectiveness claims or as authorization.

The draft deliberately separates "run the baseline re-test" from "delete
anything". The first step is the one that produces the evidence the second step
would need, which is the ordering the repository's own principles ask for.

## Friction

- What happened: Bash was unavailable for the entire session because the
  auto-mode classifier returned no verdict, including for read-only commands.
- Why it felt wrong: The repository's verification rules assume a working shell
  for `git diff --check` and file listing, and the global memory instruction
  assumes a runnable `memory` CLI at task start. Both assumptions failed at the
  same point, and the failure is not distinguishable from a permission denial
  from the agent's side.
- Impact: verification is partial and the diff-level changed-file claim rests on
  the agent's action record; the required memory lookup did not happen.
- Category: `tooling`
- Root cause guess: environment or platform condition outside the repository's
  control, not a process defect. Worth noting because the repository previously
  recorded a sandbox-verification caveat of the same general shape
  (`docs/casebook/0003-sandboxed-execution-unverified.md`); this is a new
  instance of "the verification surface is partly unavailable", not the same
  sandbox cause.

- What happened: while drafting, the two packet-shape documents were confirmed
  to be parallel near-copies at different lengths with already-divergent
  conditional wording.
- Why it felt wrong: this pair already produced a conflicting-guidance finding
  on 2026-09-08 and the duplication was not addressed then.
- Impact: a reader cannot tell from either file which copy is canonical for a
  given condition.
- Category: `process` / `context`
- Root cause guess: the repository copy and the skill reference evolved
  independently because neither is declared derived from the other.
