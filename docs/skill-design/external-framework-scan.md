# External Framework Scan

Status: design note.

## Purpose

External agent frameworks such as gstack and superpowers are design inputs, not authorities. Use them to challenge and improve this project's skills when they help explain real friction, close a skill gap, or sharpen an evaluation candidate.

The goal is selective learning. External patterns should make this project's existing evidence easier to act on, not replace local judgment or import a framework wholesale.

## Triggers

### Triggered Scan

Before changing a skill, check whether an external framework has a comparable skill or workflow. Use this when the change touches planning, review, debugging, verification, subagent handoff, idea framing, release, or safety behavior.

### Periodic Scan

Periodically review selected external framework patterns, for example monthly or after 5-8 high-signal friction items accumulate. The goal is distillation, not broad copying.

### Failure-Driven Scan

After a real-project failure or repeated friction, check whether external frameworks already encode a mature pattern for that failure mode.

## Absorption Rules

- Map every borrowed pattern to this project's real friction, skill gap, v0.3 backlog item, or evaluation watchlist.
- Record why the pattern fits and where it does not fit.
- Prefer small skill refinements or watchlist notes before policy or evaluation promotion.
- Do not treat external framework behavior as accepted internal evidence.
- Do not copy hard gates unless this project has matching evidence and a low-noise trigger.
- Preserve user sovereignty and project-specific judgment.

## Suggested Output Shape

| External pattern | Source | Problem it solves | Fit for this project | Action |
|---|---|---|---|---|

## Boundaries

- Do not read external frameworks on every task.
- Do not run broad scans without a trigger.
- Do not import large workflows wholesale.
- Do not use external framework scans to bypass this project's routing rules.
- Do not start automation or agent runtime work solely because another framework has it.
